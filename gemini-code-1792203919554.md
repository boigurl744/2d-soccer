# 2D Multiplayer Soccer Game

A top-down, real-time multiplayer 2D soccer game built with HTML5 Canvas and Firebase Firestore.

## Features
* **Multiplayer Sync**: Real-time position syncing using Firebase Firestore.
* **Landing Screen**: Choose to join the Home (Red) or Away (Blue) team.
* **Mechanics**: 
  * WASD movement (tuned for smooth, grounded gameplay)
  * Mouse aiming with smooth interpolation (lerping)
  * Dribbling physics
  * Click & hold for shot power
  * Tackling mechanism (click near the ball/player to tackle)
* **Match Logic**: 10-minute timer, scoring, and automatic field resets.

## Setup Instructions
1. Clone this repository: `git clone https://github.com/YOUR_USERNAME/multiplayer-soccer-game.git`
2. Create a [Firebase Project](https://console.firebase.google.com/) and enable **Firestore Database**.
3. In `index.html`, replace the `firebaseConfig` object with your Firebase project keys.
4. Serve the file locally (e.g., using VS Code Live Server or Python's HTTP server: `python -m http.server`).
5. Open the app in two different browser windows to test multiplayer.
